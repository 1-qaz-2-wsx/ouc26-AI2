# 指定困难实例一分钟验收

组长接手后的结果：555数据库加目标保持的主对角线估值，配合紧凑IDA*，在同机三个独立JVM中连续通过。保留成员C原提交，修复与优化单独提交；课程core未修改。

## 复现命令

安装JDK25，在仓库根目录的PowerShell运行：

```powershell
# 正确性检查
.\lab1\tools\run-leader-benchmark.ps1 -Mode Test
# 首次离线生成数据库；已有完整缓存则加载
.\lab1\tools\run-leader-benchmark.ps1 -Mode Build -Preset 555
# 三个独立Java进程；每轮都必须出现legal=true、target=PASS
1..3 | ForEach-Object {
    .\lab1\tools\run-leader-benchmark.ps1 -Mode Hard -Preset 555 -TtCapacity 1048576
    if ($LASTEXITCODE -ne 0) { throw '本轮未通过，停止验收' }
}
```

默认缓存、路径输出与日志在 `lab1/.local`，Git忽略。可用 `-CacheDirectory` 指定已有数据库目录。Hard只加载，缺失或损坏即失败，不在正式计时中建表。Java堆上限2GiB；一次离线建表上限30分钟。运行较大分组前检查至少3GiB空闲物理内存，不关闭其他软件。

正式计时从加载前开始，到搜索、恢复并独立验证路径结束；路径文件导出不计入约定口径。线程CPU时间来自ThreadMXBean，不能与总wall时间混用。没有清理操作系统文件缓存，不称为冷加载。

## 实现与正确性边界

- 通用IdAStar保留原构造器与Predictor，散列仅定位，状态相等必须比较完整布局；固定容量安全淘汰，每轮阈值独立，搜索结束释放表。使用单调时钟与long计数，兼容框架int统计。
- PackedIdAStar是可选的独立专用入口，完整64位编码、复用搜索数组、提前排除反向移动、后继排序、最后恢复Node父链。普通预测器仍用通用路径；旧SearchTester不会自动切换为此快路径。
- PackedPuzzleHeuristic提供可撤销增量游标，只重查移动数字所在组；其他组沿可逆零费用边保持估值。对称同时变换位置与数字标签，目标空格不满足保持条件时禁用。
- 旧PDB两参数loadOrBuild与默认555保留；显式分组使用带完整目标、版本、分组、长度与CRC的v3分组文件，流式保存，完成分组可复用。索引支持最多7数字，修正32位边界。不同完整分组总估值取最大值，禁止相加。
- 正确性测试覆盖强制哈希碰撞、淘汰、重复搜索、预算、零步、不可解、独立BFS最优长度、增量与完整查询、撤销、对称、保存重载与损坏拒绝。7数字只测索引边界，有限测试不等于穷举15数码。
