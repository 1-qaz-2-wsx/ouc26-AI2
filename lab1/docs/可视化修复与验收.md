# 可视化修复与验收

日期：2026-11-02。基于main 9d67121中成员D的PR #7原型，由组长授权、Codex辅助修复。D原贡献为C++/SFML二维棋盘、目录多题、键盘切题和播放；组长本轮贡献为校验、可移植构建、播放状态回归和交互改进。原始PR与提交不重写。

## 修复及优化

1. 去掉成员电脑的绝对路径，支持文件/目录参数和仓库相对目录发现。明确字体参数和Windows系统字体回退，不复制系统字体到仓库。
2. 严格检查NP_PATH_V1字段、排列、帧数量、步号、相邻合法移动及终点。零步必须等于目标；UNSOLVABLE只显示，TIMEOUT不当作无解。空文件、缺失帧等拒绝后不进入窗口。坏文件混入目录时打印具体文件及行号，只播放有效文件。
3. 修正原test_01“零步非目标”样例。原test_unsolvable数字保持，换行规范化。
4. CMake固定SFML2.6.2官方源码提交与SHA256，支持已有SFML或显式源码构建。MinGW运行库自动复制到构建目录，解决终端外启动缺DLL；不改系统PATH、不安装软件、不提交二进制。
5. 将播放状态从SFML事件处理中独立出来，验证暂停、单步边界、终点停止、切题重置、零步/无解禁播、速度范围、长帧时间与无效时间。
6. 保留深色背景和蓝色棋盘；新增鼠标按钮、进度条、播放速度0.125—2秒/步、Home/End首末帧；禁用按键重复，缩放窗口保持棋盘比例；UTF-8文件名及长标题缩略。Java搜索算法及课程core没有改动。

## 复现入口

在仓库根目录执行tools/run-visualization.ps1。Test不依赖SFML；Build可通过-FetchSFML显式构建固定版本。已有CLion但工具不在PATH时，传-ToolchainRoot指定安装目录；已有构建通过-BuildDirectory指定。Run/Check可直接使用已构建程序，不要求CMake在PATH。

```powershell
.\lab1\tools\run-visualization.ps1 -Mode Test
.\lab1\tools\run-visualization.ps1 -Mode Build -FetchSFML
.\lab1\tools\run-visualization.ps1 -Mode Check
.\lab1\tools\run-visualization.ps1 -Mode Run
```

界面验收依次选择solver-01至05：检查切题归零、上下单步、空格或Play/Pause、自动抵达终点停止、从终点重新播放、Home/End、+/-速度、鼠标操作及窗口缩放；零步与无解不能播放。所有新代码与材料位于独立修复分支，不因本地修复完成而认为已合入main。日志、class、DLL和构建缓存继续忽略；共享源码、说明、真实小型路径及截图。
